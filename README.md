# Centinela-UAP

Centinela-UAP is a personal, single-user, non-commercial Python application for reviewing and organizing a limited number of public posts from r/UFOs.

The application operates in read-only mode. It does not post, comment, vote, send messages, perform moderator actions, or interact with other Reddit users.

English-language titles and public self-text may be translated into Spanish entirely on the user's computer using an offline translation tool. Reddit content is not sent to an external translation service and is not used to train artificial intelligence or machine-learning models.

The application maintains a small local index for personal review. It does not create user profiles, infer sensitive attributes, sell or redistribute Reddit data, or provide Reddit data to third parties.

If Reddit indicates that a previously retrieved post has been deleted or removed, Centinela-UAP deletes the locally stored records associated with that post.

The application accesses only r/UFOs, requests only the minimum public data required for this purpose, and is designed to comply with Reddit's applicable API limits and policies.
